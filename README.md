# WORLD DOMINION

**대전략 국가 시뮬레이션 · 세계 시뮬레이션 · 샌드박스** — 국가, 전쟁, 문명, 역사의 시뮬레이션.

플레이어가 한 국가를 직접 통치할 수도 있고, 아무것도 조종하지 않은 채 AI 국가들이 스스로 발전하고 동맹을 맺고 전쟁하며 역사를 만들어 가는 모습을 관찰할 수도 있는 브라우저 게임입니다. 서버 없이 GitHub Pages에서 동작합니다.

## 세계 유형

- **🌍 실제 세계 2025** — Natural Earth 국경 데이터를 래스터화한 실제 세계 지도와 178개 실제 국가. 실제 인구·경제 규모·정부 형태·수도·동맹(NATO, CSTO 등)·적대 관계·핵보유국이 반영되고, 이후의 역사는 시뮬레이션이 만들어 간다. (지형은 주요 산맥·사막·밀림·강을 근사)
- **🎲 가상 세계** — 무작위 대륙·국가 생성 (소/중/대형, 시작 연도 선택)

## 플레이

- **👑 국가 통치** — 세율·징병·예산·체제, 건설, 연구, 외교(15종), 육군 편성과 이동, 해군·공군, 평화 협상
- **👁 세계 관찰** — 개입 없이 AI 국가들의 흥망성쇠를 지켜봄 (최대 30배속)
- **⚡ 신 모드** — 전쟁 강제, 국가 통합·분열·건국·삭제, 재해, 기술·자금·인구 조작, 세계 규칙 변경, 역사 빨리 감기
- **✏ 시나리오 편집** — 지형 브러시(바다·산맥·강 등), 영토 칠하기, 국가 속성·시작 연도 설정

모드는 게임 중 언제든 상단 바에서 바꿀 수 있습니다.

### 재미 요소
- **월드박스식 유닛 표현** — 확대하면 사단이 걸어 다니는 병사·전차·포·트럭·수송선으로 보이고, 전투 지역에는 총구 섬광과 폭발, 도시에는 주민이 오간다
- **결정 이벤트** — 파업, 과학자 망명, 국경 충돌, 스캔들, 영웅 장군, 난민, 유전 탐사 등 선택에 따라 결과가 달라지는 사건
- **첩보** — 기술 탈취·반정부 선동·산업 시설 파괴 (발각 시 관계 악화)
- **핵무기** — 핵 억제(핵보유국은 침공 대상이 되기 어려움), 핵 개발, 핵 공격과 보복, 세계적 비난
- **업적 10종과 승리 조건** — 세계 인구의 40%를 지배하면 세계 패권 달성
- **배속** — 1x · 2x · 5x · 10x · 30x · 100x · MAX (프레임 예산 안에서 최대한 빠르게)
- **알림 설정** — 전체 / 주요 / 내 국가+세계적 사건 / 끄기 (모바일 기본값은 작고 적게). 일반 외교 제안은 📨 우편함에 쌓이고, 평화 협상·최후통첩만 즉시 표시

## 시뮬레이션 개요

- **세계 생성**: 노이즈 지형(12종), 강·호수, 프로빈스 분할, 문화·종교권, 국가 배치 — Web Worker에서 생성
- **경제**: 프로빈스별 식량·공업·서비스 생산 → GDP, 자원 5종의 국제 시장 가격, 수입·수출, 실업, 물가, 부채·국가 부도, 경기 순환, 공산품 시장 포화(무한 성장 방지)
- **인구**: 출생·사망·수용력(로지스틱), 기근, 전염병 확산, 이주·난민, 도시 6단계
- **정치**: 8개 정부 형태, 안정도·정통성·불만, 선거, 쿠데타, 혁명, 내전, 독립운동, 평화적 통합
- **외교**: 관계 −100~100, 조약(동맹·불가침·무역·경제협력·통행권·보장·제재), 종속국, 최후통첩, 국경 분쟁
- **전쟁**: 8개 병종, 일 단위 반복 전투 계산 `P_atk = A×M×S×T`, `P_def = D×F×E×R`, 보급(수도·항구→철도·지형), 포위 섬멸, 점령, 전쟁 점수, 항복, 평화 협정(할양·배상·종속·병합·정권 교체·독립·비무장지대), 휴전, 세계대전 승격
- **AI**: 국가 성격 8종 × 상황 판단(위협·경제·전쟁 비용·동맹 전력), 장기 목표, 전선 작전·상륙, 평화 협상
- **문명**: 기술 9분야(이웃 국가로부터 확산), 시대, 자연재해 8종, 기후 변동, 종교 탄생·확산, 문화 동화
- **역사 기록**: 모든 주요 사건이 연대기로 자동 기록되어 세이브에 포함

## 저장

IndexedDB 자동 저장(3슬롯 순환 백업)·수동 저장·덮어쓰기·삭제, JSON 내보내기/가져오기, 세이브 버전 관리·마이그레이션·데이터 검증.

## 개발

```bash
npm install
npm run dev        # 개발 서버
npm run build      # 타입 검사 + 프로덕션 빌드 (dist/)
npm run sim-test -- 100 medium   # 헤드리스로 100년 시뮬레이션 검증
node scripts/build-realworld.mjs  # 실제 세계 지도 데이터 재생성 (src/data/realworld.json)
```

기술 스택: React + TypeScript + Vite + PixiJS(WebGL 지도) + idb(IndexedDB) + Web Workers.

```
src/
├── components/   React UI (상단/좌측/우측/하단 패널, 모달, 메인 메뉴)
├── map/          PixiJS 지도 엔진 · 픽셀 렌더러 · 카메라 · 오버레이 레이어
├── simulation/   세계 생성 · 경제 · 인구 · 정치 · 외교 · 군사 · 전쟁 · 환경 · 사건
├── ai/           국가 · 경제 · 외교 · 군사 AI
├── systems/      게임 컨트롤러 · 저장/불러오기 · 설정 · 알림 · 지도 입력
├── editor/       세계 편집 · 신 모드 · 시나리오 설정
├── workers/      세계 생성 / 역사 빨리 감기 Web Worker
├── data/         지형 · 건물 · 병종 · 기술 · 정부 · 이름 정의
└── types/        Province · Country · Military · World 타입
```

## 배포

`npm run build` 는 `docs/` 에 빌드 결과를 만들고, 저장소 루트의 `index.html` 도 빌드된 페이지로 갱신합니다. 이 결과물은 저장소에 커밋되므로 GitHub Pages 를 **Settings → Pages → Deploy from a branch → `main` / `(root)`** (또는 `/docs`) 로 설정하면 바로 동작합니다. `main` 에 push하면 GitHub Actions 가 빌드·시뮬레이션 테스트를 실행하고, 빌드 결과가 바뀌었으면 자동으로 커밋합니다.

개발용 HTML 진입점은 `app/index.html` 입니다 (`npm run dev`).
